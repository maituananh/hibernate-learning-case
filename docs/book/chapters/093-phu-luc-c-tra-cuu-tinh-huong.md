## Phụ lục C. Bảng tra tình huống

Bảng dưới đây liệt kê mọi tình huống của lab, theo mã tình huống. Với mỗi mã bạn có: mục trong sách, mức (Cốt lõi hoặc Mở rộng), class test và method test trong repository. Dùng bảng này khi bạn đang đọc code của lab và muốn biết sách giải thích tình huống đó ở đâu, hoặc ngược lại.
